# Jogo de Adivinhação em Python

Projeto simples desenvolvido em Python com o objetivo de praticar lógica de programação, estruturas de repetição e condicionais.

## 📌 Sobre o projeto
O jogo gera um número aleatório entre 1 e 50, e o jogador possui 5 tentativas para acertar o número escolhido pelo computador.

Durante as tentativas, o sistema fornece dicas informando se o número secreto é maior ou menor que o palpite digitado.

## 🚀 Tecnologias utilizadas
- Python

## 🎮 Funcionalidades
- Geração de número aleatório
- Sistema de tentativas
- Dicas para auxiliar o jogador
- Mensagem de vitória
- Sistema de Game Over
